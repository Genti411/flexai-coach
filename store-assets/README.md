# Store assets

Screenshots captured from the running app (web build at a 390x844 phone viewport,
via Playwright) for App Store / Play Store listings. They double as evidence the app
runs interactively, not just that it bundles.

| File | Shows |
|---|---|
| `01-consent.png` | First-run consent gate (disclaimer + privacy) |
| `02-chat-home.png` | Chat home: welcome, prompt chips, disclaimer banner, input |
| `03-neck-response.png` | "Neck tension" -> stretch cards (offline engine, no API key) |
| `04-safety-block.png` | "chest pain and numbness" -> safety block, **no exercises** (guardrail working live) |
| `05-settings.png` | Settings: fitness level, goals, Export/Delete my data, legal links |
| `06-legal.png` | In-app Legal & Safety (disclaimer, privacy, terms, copyright) |

Notes for submission:
- These are functional captures with placeholder branding. Replace the generated
  icon/`F` mark with designed artwork and consider framed device mockups before
  publishing.
- Stores require specific sizes/aspect ratios (e.g., 6.7" iPhone, various Android
  sizes). Re-capture at required dimensions or frame these.
