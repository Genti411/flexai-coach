# Stretch Illustration Prompt Sheet (for ChatGPT / DALL-E)

Generate one image per stretch and save it with the **exact filename** listed
(lowercase, `.png`) into `assets/stretches/`. The app shows the image when present
and falls back to the built-in animation otherwise, so you can do them a few at a
time.

There are 38 unique images (Child's Pose is shared by two stretches).

## How to get consistent results
1. Generate them all in **one ChatGPT session**.
2. For the **first** image, paste the full prompt below (it starts with the STYLE
   PREFIX).
3. For every image after, you can shorten to:
   `Same character, style, palette, framing, and plain light-gray background as the
   previous image. Now show: <the pose line>.`
4. Use a **square** image (1024x1024). PNG. Plain very-light-gray (or transparent)
   background.

## Copyright rules (keep it clean)
- **Original, generic character** - not a real, famous, or recognizable person.
- **No** logos, brand names, trademarks, or jersey/clothing brands.
- **No** "in the style of <artist/studio/brand>" - just "modern flat vector
  illustration".
- You own the outputs you generate (per OpenAI's current terms - confirm them).
  Keep this sheet as your record; it's referenced in
  `docs/legal/content-licenses.md`.

## STYLE PREFIX (used at the start of each prompt)
> Modern flat vector illustration of one friendly athletic adult in plain workout
> clothes, clean bold outlines, soft cel shading, calm palette with a teal accent,
> plain light-gray background, full body centered, original generic character (not a
> real or famous person), no text, no logos.

Optional: add `Include a small subtle teal arrow showing the direction of the
movement.` to any prompt if you want the reference's "motion arrow" look.
